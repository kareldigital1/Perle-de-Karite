# 🌿 Perle de Karité — Site Vitrine Premium

Site web vitrine ultra-premium pour la marque de cosmétiques naturels **Perle de Karité**, spécialiste du beurre de karité béninois et des soins de beauté africains haut de gamme.

## 📦 Contenu du dépôt

- **index.html** – page complète (HTML, CSS, JS intégrés) responsive, animations fluides, loader, modale produits, formulaire de contact, WhatsApp flottant, révélations au scroll.

## ✨ Caractéristiques

- Design luxe minimaliste, inspiré d'Aesop, Fenty Skin, Dior Beauty
- Palette de couleurs premium (vert olive, beige naturel, doré luxe)
- Typographies Playfair Display, Cormorant Garamond, Montserrat
- 8 sections : Hero, À propos, Produits, Avantages, Témoignages, FAQ, Contact, Footer
- Modale détaillée pour chaque produit avec avantages clés
- Boutons WhatsApp et formulaire de contact fonctionnel
- 100% responsive (mobile, tablette, desktop)
- Animations CSS/JS élégantes, parallaxe léger, compteurs animés

## 🚀 Utilisation

1. Cloner le dépôt
2. Ouvrir `index.html` dans un navigateur (de préférence via un serveur local pour le chargement des images)
